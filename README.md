### 4. vitris_LED.vhd
**用途**: FPGA端LED控制器源代碼  
**功能**:
- 實現完整的AXI4-Lite Slave接口
- 支持寫操作（控制LED）
- 支持讀操作（讀取LED狀態）
- 包含2個32位暫存器（LED_CONTROL和STATUS）
- 8位LED輸出驅動

**類型**: VHDL硬體描述語言  
**目標**: Xilinx Zynq-7000 PL端

---

### 5. led_pins.xdc
**用途**: FPGA引腳約束文件  
**功能**:
- 定義LED[7:0]的物理引腳位置
- 設置I/O標準（LVCMOS33）
- 根據ZC702板卡硬體設計

**類型**: Xilinx Design Constraints  
**使用**: 在Vivado中添加到專案

---

### 6. main.c
**用途**: ARM處理器端應用程式  
**功能**:
- UART初始化與數據接收
- AXI總線寫入操作
- 輸入驗證（0-8範圍檢查）
- LED控制邏輯
- 用戶介面（CLI）
- 狀態回讀與顯示

**類型**: C語言源代碼  
**目標**: ARM Cortex-A9 (PS端)

## 🚀 快速開始

### 對於初次使用者：
1. **先閱讀**: `SDD_系統設計文檔.md` - 了解整體架構
2. **然後參考**: `開發指南.md` - 按步驟進行開發
3. **需要時查閱**: `LED控制暫存器規格.md` - 理解寄存器定義

### 對於硬體開發者：
1. 使用 `vitris_LED.vhd` 作為IP核源文件
2. 參考 `led_pins.xdc` 設置引腳約束
3. 查閱 `SDD_系統設計文檔.md` 第4節了解介面規格

### 對於軟體開發者：
1. 使用 `main.c` 作為應用程式基礎
2. 查閱 `LED控制暫存器規格.md` 了解暫存器操作
3. 根據實際地址修改 `LED_CONTROLLER_BASE` 宏
