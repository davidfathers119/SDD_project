# FFT 訊號處理系統

## 專案概述

本專案實作一個完整的 FFT (Fast Fourier Transform) 訊號處理系統，整合 Visual Basic (VB) 介面與 FPGA 硬體加速運算，透過 RS-232 串列通訊進行資料傳輸。

## 系統架構

```
[VB 應用程式] <---> [RS-232] <---> [FPGA FFT 處理器] <---> [RS-232] <---> [VB 應用程式]
    ↓                                       ↓                                    ↓
 波形輸入                              FFT 運算                              頻譜輸出
 時域顯示                              硬體加速                              頻域顯示
```

## 主要功能

### 1. VB 端功能
- **波形產生與輸入**
  - 使用者可輸入或匯入時域訊號資料
  - 支援多種波形產生（正弦波、方波、三角波等）
  - 即時顯示原始時域波形圖表

- **資料傳輸**
  - 透過 RS-232 串列埠傳送波形資料至 FPGA
  - 設定通訊參數（鮑率、資料位元、停止位元等）
  - 資料封包處理與錯誤檢查

- **結果接收與顯示**
  - 從 FPGA 接收 FFT 運算結果
  - 繪製頻域頻譜圖
  - 顯示振幅、相位資訊
  - 支援資料匯出功能

### 2. FPGA 端功能
- **RS-232 通訊介面**
  - 接收來自 VB 的時域資料
  - 傳送 FFT 運算結果回 VB
  - 通訊協定處理與同步

- **FFT 運算核心**
  - Radix-2 DIT/DIF FFT 演算法
  - 可配置 FFT 點數（64/128/256/512/1024 點）
  - 複數運算處理（實部、虛部）
  - 固定點數運算優化

- **資料緩衝與控制**
  - 輸入資料緩衝區
  - 輸出資料緩衝區
  - 狀態機控制流程
  - 中斷與握手訊號處理

## 資料流程

### 完整處理流程

1. **波形輸入階段**
   - VB 程式產生或讀取時域訊號資料
   - 在 VB 介面繪製原始波形圖
   - 資料預處理（正規化、量化）

2. **資料傳輸階段（VB → FPGA）**
   - VB 將時域資料封包化
   - 透過 RS-232 序列傳輸至 FPGA
   - FPGA 接收並儲存於輸入緩衝區
   - 確認接收完成訊號

3. **FFT 運算階段**
   - FPGA 觸發 FFT 運算
   - 執行蝴蝶運算與旋轉因子計算
   - 產生頻域複數結果（實部、虛部）
   - 計算振幅與相位

4. **結果傳輸階段（FPGA → VB）**
   - FPGA 將 FFT 結果封包化
   - 透過 RS-232 傳回 VB
   - VB 接收並解析資料

5. **頻譜顯示階段**
   - VB 處理頻域資料
   - 繪製頻譜圖（振幅 vs 頻率）
   - 顯示主要頻率成分
   - 提供分析工具（峰值偵測、諧波分析等）

## 系統特點

### 優勢
- **硬體加速**：使用 FPGA 進行 FFT 運算，速度遠快於軟體實作
- **即時處理**：支援即時訊號處理與頻譜分析
- **視覺化介面**：VB 提供友善的圖形介面
- **彈性配置**：可調整 FFT 參數與通訊設定
- **低成本**：使用標準 RS-232 介面，無需特殊硬體

### 應用場景
- 訊號頻譜分析
- 聲音訊號處理
- 振動分析
- 通訊系統測試
- 教育訓練與實驗

## 技術規格

### 硬體規格
- **FPGA 晶片**：Altera Cyclone III EP3C40Q240
- **開發工具**：Intel Quartus II
- **FFT 點數**：256 點（固定）
- **系統時鐘**：50 MHz
- **資料寬度**：16-bit 固定點數

### 軟體規格
- **開發環境**：Visual Studio 2022
- **框架版本**：.NET 6.0 (LTS) 或 .NET 7.0
- **專案類型**：Windows Forms Application
- **通訊介面**：RS-232 (115200 bps)

詳細技術規格請參閱 [spec.md](spec.md)
